# Go API client for v1

Using Notifications API, you can manage notifications for account, billing and service events.
Additionally, you can configure how you are notified for some of the notification types.
By default, notifications are sent by email to the organization’s administrator or if using RBAC,
a user with the `OrganizationAdmin` role.
All other RBAC roles have read-only access to notifications.

For notifications, you should understand the following terms:

**Notification Type**: The type of notification based on the Confluent Cloud event that has occured.
These are categorized by Account, Billing and Licensing, Service, and more, and they can be filtered
by by severity level. For example, a dedicated cluster shrink failure is a warning-level service
notification type.

**Integration**: Describes the configured notification channel for sending a notification
event - Email, Microsoft Teams, Slack or a generic Webhook. The default integration is email, and
notifications are sent to the organization’s admin or if using RBAC, a user with the `OrganizationAdmin` role.

**Subscription**: Represents the association of a notification type to an integration channel.
A customer creates subscriptions for a particular notification type and as a result is notified
through the integration channels they have configured for that subscription. By default,
notifications are subscribed to an email integration and emails are sent to email addresses for
organization admins associated with the account.

You can view the current notification subscriptions and configure additional integrations and
subscriptions to those integrations using the REST APIs.
For example, you can configure a Slack integration, and then subscribe to this integration for a
Kafka cluster shrink failure. You can manage notifications for account, billing and service events
with the REST APIs. Additionally you can configure how you are notified for some of the notification types.
By default, notifications are sent by email to the organization’s administrator or if using RBAC,
a user with the OrganizationAdmin role. All other RBAC roles have read-only access to notifications.
