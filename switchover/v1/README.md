# Go API client for v1

The Switchover API powers Confluent Cloud's Disaster Recovery (DR) experience for Kafka.

It exposes two resources:
  * `SwitchoverPair`     - models a cluster-level DR pairing between two Kafka clusters
                           (an active member and a passive member) and the failover/switchback
                           operation between them. Only stateful workloads (e.g. Kafka) use it.
  * `SwitchoverEndpoint` - models the endpoint-level DR configuration that derives its routing
                           target from a `SwitchoverPair` and exposes a sticky DR endpoint clients
                           connect to, so they never have to update their bootstrap endpoint after
                           a failover.

The API allows you to list, create, read, update, and delete these resources, and to trigger a
failover on a pair.
